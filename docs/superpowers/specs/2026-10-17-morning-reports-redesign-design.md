# 아침 리포트 개편 설계 — Daily Market · ETF Today

2026-10-17. 운영자와의 브레인스토밍(브라우저 시안 포함)으로 합의한 내용. 근거 자료: `docs/audits/2026-10-16/`(Codex 운영·콘텐츠·디자인 감사), 2026-10-16 배포분(사실 검증·출처·발송 신뢰성).

## 1. 목적과 독자

- **독자:** 기관·전업 투자자가 아닌, 주식·금융상품 경험이 조금 있는 개인 금융 고객. iM뱅크 내부 직원과 고객이 같은 글을 본다(직원은 고객 응대 소재로도 사용).
- **독자가 얻어 갈 것:** ① 전날 한국·미국 시장의 대략적 분위기 ② 오늘 시장 방향에 대한 기본 정보 ③ 보유 자산 판단과 새 포지션에 대한 '감'(사라/팔라가 아닌 판단 재료와 확인 조건).
- **부가 목적:** AI가 생성한 리포트로 iM뱅크의 AI 역량을 보여준다. 화려한 연출보다 매일의 정확성과 해석의 질로 보여준다(틀린 숫자 하나가 역량 홍보를 무너뜨린다).
- **유통:** 텔레그램 채널은 리포트 웹 URL만 전달한다. iM뱅크 앱·웹·카카오톡 등은 그날 URL을 사람이 옮겨 붙이거나, 사이트 메인·아카이브를 고정해 띄운다. → **웹 페이지가 유일한 본체**, 각 메신저의 **링크 미리보기 카드가 첫인상**, 대부분 **모바일**에서 열린다.

### 성공 기준
1. 독자가 미리보기 카드나 페이지 상단만으로 1~2분 안에 "어제 분위기 / 오늘 볼 것 / 내 자산군에 주는 의미"를 얻는다.
2. 깊이 읽고 싶은 독자는 아래에서 근거와 상세 데이터를 찾는다.
3. 두 리포트가 매 영업일 **08:00 전**에 함께 발송된다.
4. 기존 링크·메인·아카이브·연계 업무가 깨지지 않는다.

## 2. 지켜야 할 조건 (변경 금지)

- **주소 유지:** `/reports/YYYY-MM-DD`, `/etf-reports/YYYY-MM-DD`, 메인(`/`), 아카이브(`/archive`)의 경로와 구성. 과거 리포트 HTML은 그대로.
- **두 리포트 유지:** 각각 생성·게시. 이름 "Daily Market"·"ETF Today" 유지(통합 이름 불필요).
- **F02 정책 유지:** "품질 낮아도 전송 > 침묵". 사실 검증은 재생성 사유이고, 마지막 축소판에서는 경고만 남기고 발송한다.
- **준법:** 법적 고지는 페이지 맨 마지막. 매수·매도 권유 표현 금지. 신규 형식의 준법 검토는 운영자가 별도로 처리한다.
- 2026-10-16 배포한 사실 검증(수치 대조·기간·환율 방향·근거·추론 경계·일정 시각)과 발송 신뢰성(배포 확인·자산 확인·도착 감시)은 새 형식에도 그대로 적용한다.

## 3. 페이지 구성

공통:
- 모바일 기준으로 지금보다 크게 줄인다(ETF 모바일 약 32화면 → 목표 8~10화면). 핵심은 위, 상세는 펼쳐 보기.
- 상단 **세 줄 요약 상자**(브레인스토밍 A안). "어제" 줄은 숫자 나열이 아니라 분위기·배경을 말로 쓰고, 숫자는 바로 아래 핵심 지표에 근거로 둔다.
- 상단에 AI 작성 시각·데이터 수 같은 메타 줄은 두지 않는다. AI 표기는 기존 머리글 "iM AI Analyst"와 법적 고지로 충분하다.
- 카드 배경 그림(스트라이프·모자이크)을 페이지 머리에도 같은 모양으로 두고, 그 아래 한 줄로 무엇인지 설명한다(범례는 카드에 넣지 않는다).
- 숫자는 가능한 한 **코드가 데이터에서 렌더**하고, 모델은 문장(해석)을 쓴다. 모델 산문 속 숫자는 기존 수치 대조 검증을 거친다.
- "갖고 있다면 / 새로 본다면"은 조건·관찰형 문장만. 대표 ETF는 "예시"로 표기.

### 3.1 Daily Market — 어제와 오늘

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 머리글 + 스트라이프 | 로고·이름·날짜, 최근 20거래일 코스피 띠 + 한 줄 설명 |
| 2 | 제목·부제 | 카드와 같은 제목 |
| 3 | 세 줄 요약 | 어제(분위기를 말로) / 오늘 볼 것 / 내 자산은 → ETF Today 링크 |
| 4 | 핵심 지표 6개 | 기본 5개(코스피·S&P500·나스닥·원/달러·미 10년물) + 그날 변수 1개(유가·금 등) |
| 5 | 어제 무슨 일이 있었나 | 4~6문단: 사건 → 근거 있는 원인 → 시장 반응 |
| 6 | 오늘 볼 것 | 최대 3개, 한국시간 순서. 미국 발표는 "장 마감 후 → 다음 거래일 반영" |
| 7 | 한국 시장에 주는 의미 | 2~3개, "확인되면 / 어긋나면" |
| 8 | 펼쳐 보기 | 전체 지표 13개, 이번 주 일정표, 과거 비교 |
| 9 | 참고한 뉴스 · 데이터 기준 · 법적 고지(맨 끝) | |

제거: 자산군별 온도계(compass) — 자산군 관점은 ETF Today가 맡는다. 시장 모드(event/normal/quiet)는 5번 분량 조절에만 쓴다.

### 3.2 ETF Today — 내 자산군 관점

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 머리글 + 모자이크 | ETF 모자이크(Korea / USA) + 한 줄 설명 |
| 2 | 제목·부제 | 카드와 같은 제목 |
| 3 | 세 줄 요약 | 해외 신호 / 국내 상태 / 오늘 핵심 |
| 4 | 자산군별 판단 재료 | 5~6개 카드(국내 대형주, 국내 반도체·IT, 그날 움직인 국내 섹터, 미국 주식(환노출), 채권, 금·원자재). 카드마다: 어제 움직임(대표 ETF 예시·등락은 코드 렌더) / 이유(근거 있을 때만) / 갖고 있다면 / 새로 본다면. 그날 중요한 순서 |
| 5 | 오늘 확인할 것 3가지 | 시각 + 비교 기준 + 어긋나면 버릴 가설 |
| 6 | 레버리지·인버스 주의 | 변동성이 큰 날에만 |
| 7 | 펼쳐 보기 | 국내·미국 ETF 표(등락, 추정 거래대금) |
| 8 | 참고한 뉴스 · 데이터 기준 · 법적 고지 | 데이터 기준: 전일 종가. NAV·괴리율은 "주문 전 장중 iNAV 확인" 안내 |

제거: Decision Frame(검은 결론 패널), Story·Characters, 전략 지도, 매칭표, 이슈 카드, 액션 보드(괴리율), 규칙 점수 표시. 국내 급락일 판단(C06)은 화면에서 빼고 문장 생성 기준으로만 쓴다.

## 4. 링크 미리보기 카드

원칙: 휴대폰 미리보기에서 카드 폭은 약 300pt → **큰 요소 2~3개만**, 제목 외 글자 최소. 숫자는 숫자 자체가 뉴스일 때만 제목 안에. 지수 등락률처럼 다른 곳에서 이미 보는 숫자는 카드에 넣지 않는다. 세부는 메신저가 자체 글꼴로 보여주는 설명 문구(og:description)로.

| 배경 데이터 | 최근 20거래일 코스피 **스트라이프**(하루 = 세로 줄, 휴장일 없음, 마지막 줄 아래 ▼ = 어제) | 분석한 ETF **모자이크**(Korea 왼쪽 / USA 오른쪽, 레버리지·인버스 제외, 자산군별 묶음 → 그 안에서 등락순) |

## 5. 생성·발송 흐름 (08:00 전)

| 시각(KST) | 동작 |
|---|---|
| 06:40 | 맥미니 launchd 1차 트리거 → Market·ETF **병렬 생성**(한 번의 dispatch) |
| ~06:50 | 각자 생성·검증·커밋(push 재시도) |
| ~06:55 | **발송 job 하나**가 Vercel 배포·공개 자산 확인 후 두 리포트를 연달아 발송(Market → ETF, 메시지별 미리보기) |
| 07:20 | 2차 트리거 — 생성된 것은 건너뛰고 빠진 리포트만 생성·발송 |
| 07:45 | 도착 감시 — 영업일에 둘 중 하나라도 미발송이면 경보(GitHub 실패 메일) |

- 생성 job은 발송하지 않는다. 발송 job은 두 생성 job이 끝나면(성공·실패 무관) 실행하고, **준비된 리포트는 기다리지 않고 보낸다**(전송 > 침묵). 발송 상태 기록(commit status `telegram/<kind>`)·중복 방지·결과 불명 경보는 기존 규칙 그대로.
- 휴장 처리: 기존 리포트별 규칙 유지(한국 휴장 → ETF 생략 등). 발송 job은 그날 만들어진 리포트만 보낸다.
- 트리거 정리: ETF 08:15·08:40 제거, Market·ETF가 06:40·07:20을 공유. 도착 감시 07:45 하나(두 리포트). cron-job.org 잔여 작업은 전환 전에 삭제(운영자).
- 미국 서머타임 종료(11/1) 후 미국 장 마감은 한국시간 06:00 → 06:40에 40분 여유.

### 데이터 변화
- ETF: KRX OpenAPI(08:00 게시)를 쓰지 않는다. 국내 ETF는 전일 종가·등락(Yahoo), 거래대금은 가격×거래량 추정. KRX 조회 코드는 남겨 두되 06:40에는 데이터가 없어 기존 안전장치(stale/none → 병합 안 함)로 자동 생략.
- 괴리율 기반 이상 탐지는 사라지고 거래량 급증 탐지는 유지.
- 카드 데이터: 코스피 20거래일 일봉(Yahoo, 휴장일 제외), ETF 유니버스 전일 등락(이미 수집).

## 7. 전환 · 테스트

- **병행 운영 없이 바로 적용.** 전환 전 주말에 dry-run 테스트(실제 데이터로 생성까지, 커밋·발송 없음)를 한다. 주말에는 휴장 판정으로 생략되므로 날짜 지정(평일 날짜)으로 실행한다.
- 테스트: 새 화면 구성(섹션 순서·분량·법적 고지 마지막·조건형 표현), 카드 PNG(규격·글자 수 한도·로고 원본·폰 크기 가독), 병렬 생성 + 발송 job(둘 다 성공·한쪽 실패·2차 트리거), 도착 감시 07:45, 휴장일, 기존 주소·아카이브, 수치 대조가 새 섹션(자산군 카드 문장 포함)에도 적용되는지.
- 되돌리기: 병합 커밋 revert + 이전 launchd 트리거 재설치. 과거 리포트·주소는 영향 없음.
